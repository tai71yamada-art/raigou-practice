# ブラウザでの確認（playwright ＋ Chrome が必要）

作り替えの前後で「見た目も動きも同じか」を確かめる道具です。

| ファイル | 中身 |
|---|---|
| `record.py html out.json` | 乱数を固定してAI同士で72局。ログの全行を保存（前後で同じなら、ルールとAIの動きは同じ） |
| `screens.py html outdir` | 主な画面（スタート・キャラ選択・ガイド・設定・対戦・結果）のスクリーンショット。前後で画素を比べる |
| `humanbot.py html out.json [局数]` | あなたの席をでたらめに操作するボットで対局。止まる・エラー・駒の数の狂いがないかを見る |

v35 の作り替えでは、v34 と比べて「ログ72局が完全一致」「画面30枚が一致（設定画面のバージョン表示だけ違う）」を確認しました。
また humanbot で、浄の「捨てて引き直す」を2度押しすると駒が増えて置き直しが決められなくなる不具合が見つかり、直しました。
