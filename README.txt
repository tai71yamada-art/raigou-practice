雷轟 練習アプリ（ホーム画面に追加できる版）

このフォルダの中身をまとめて https のサイトに置くと、
スマホのホーム画面に追加して、アプリのように全画面で遊べます。
一度開けば、その後はオフラインでも遊べます。

置き方の例（どれも無料で使えます）
・Netlify Drop（https://app.netlify.com/drop）にこのフォルダをドラッグ＆ドロップ
・GitHub Pages に、このフォルダの中身をそのまま置く

ホーム画面への追加
・iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
・Android：Chromeで開く → メニュー → 「ホーム画面に追加」（または「アプリをインストール」）

アプリを更新したとき
・index.html を差し替え、sw.js の VERSION（raigou-v1）を raigou-v2 のように変えてから置き直すと、
  ホーム画面のアプリにも新しい版が届きます。

※ BGM（bgm.mp3）は別ファイルです。index.html と同じ場所に置いてください。
※ index.html だけをファイルとして直接開いた場合は、BGMとオフライン機能・アイコンは無しで遊べます。
※ iPhoneからアップロードする時は、zipを「ファイル」アプリで開いて展開し、できたフォルダごと選んでください（うまくいかない時はパソコンから）。
